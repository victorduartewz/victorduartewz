## About me

I'm a front-end developer focused on building fast, responsive and well-crafted web applications with **React**, **Next.js** and **TypeScript**. I've shipped landing pages, admin dashboards, finance platforms and portfolio sites, and I also work across the stack with **Node.js**, **Fastify** and **PostgreSQL** when a project calls for it.

- 🎓 Studying **Systems Analysis and Development** at FACINT
- 💼 Building production interfaces with modern tooling and design systems
- 🤖 Currently exploring **AI automation** and **Web3 development**
- 📫 Reach me at **contato.vhzborges@gmail.com**
